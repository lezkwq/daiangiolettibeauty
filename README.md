# Dai Angioletti Beauty

Site institucional de Dai Angioletti Beauty, em Camboriú, SC.

## Desenvolvimento local

Requer Node.js e Bun.

```sh
bun install
bun run dev
```

## Fotos

As fotos ficam em `src/assets/` e seus textos alternativos e identificadores estão registrados em `src/components/site/photos.ts`. Os blocos usam `data-photo-slot` para facilitar ajustes de enquadramento.

## Informações comerciais

Contato, endereço, Instagram e links de agendamento ficam em `src/components/site/contact.ts`.
